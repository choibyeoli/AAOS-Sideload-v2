Phase 0: 권한 탈취 사전 작업 필수 확인

OS가 설치 요청을 묵살하지 않도록, 현재 브라우저(Whale/Vivaldi)에 '알 수 없는 앱 설치' 권한이 부여되어 있는지 확인합니다.

Method A: System Exploits 핵폭탄급/최우선

파일 시스템 차단 정책(MDM)을 원천 우회하기 위해, 안드로이드 OS의 숨겨진 관리자 메뉴 및 디버깅 옵션을 강제로 팝업시킵니다.

Method B: RAM-to-Share Injection Golden Ticket

디스크 저장을 생략하고 브라우저 메모리에 페이로드를 적재한 뒤, Share API 및 내비게이션 우회로 시스템 패키지 인스톨러로 직접 넘깁니다.

Method C: OPFS Sandbox Injection Persistence

브라우저 샌드박스 내부의 암호화된 가상 파일 시스템(OPFS)에 페이로드를 영구 은닉한 후 Share API로 토스합니다.

Method D: FSA API Async Override Patch Applied

스트림 수신 전 OS 네이티브 저장소 핸들을 먼저 획득하여 User Gesture 타임아웃 예외를 우회합니다.
